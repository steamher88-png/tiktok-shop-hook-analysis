# TikTok Shop: Emotional vs Rational Hooks

Учебный проект по аналитике данных. Цель — проверить, различается ли конверсия в просмотр страницы товара между видео с эмоциональным (Emotional) и рациональным (Rational) хуком.

## Задача

Сравнить конверсию двух типов хуков и проверить, является ли наблюдаемая разница статистически значимой.

## Данные

Исходный датасет содержит 100 000 наблюдений и более 180 признаков. После фильтрации по типу хука, качеству данных, аномалиям и пропускам в используемых полях осталось 45 674 наблюдения:

- Emotional — 22 800 наблюдений.
- Rational — 22 874 наблюдения.

Источник: [TikTok Shop Viral Sales and CAC Attribution — Kaggle](https://www.kaggle.com/datasets/datascikhan/tiktok-shop-viral-sales-and-cac-attribution)

## Методы

- Очистка и подготовка данных.
- Проверка сопоставимости групп по количеству подписчиков авторов.
- Расчёт конверсии в просмотр страницы товара.
- Проверка статистической значимости с помощью критерия хи-квадрат.

## Основные результаты

- Конверсия Emotional — 0,798%.
- Конверсия Rational — 0,739%.
- Наблюдаемая разница — 0,059 процентного пункта в пользу Emotional.
- Результат критерия хи-квадрат = 0,4535, p-value = 0,50.

При уровне значимости 0,05 статистически значимых различий между группами не обнаружено. Несмотря на небольшое преимущество Emotional в выборке, имеющихся данных недостаточно, чтобы уверенно утверждать о различии конверсий.

## Вывод

По результатам анализа нельзя обоснованно рекомендовать эмоциональный или рациональный хук как более эффективный. Для принятия решения потребуются дополнительные данные или дальнейшее исследование.
